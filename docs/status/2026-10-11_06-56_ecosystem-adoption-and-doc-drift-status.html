The value proposition is no longer hypothetical

The README and ROADMAP still frame adoption as "planned" and "unproven". Six internal repos now import the SDK. The next honest question is not "does anyone use it?" but "has any of them deleted its converter layer yet?" That is the real migration metric, and it is still unverified.

The go-finding sub-module "lockstep" claim is inaccurate

AGENTS.md states sub-modules "release in lockstep" with the root. The proxy shows root at v1.14.0 but toolsdk at v1.15.0 (and toolsdk carries its own v1.13.1 patch). They are independently versioned in practice. Harmless to this SDK (it imports only the root) but a wrong mental model in memory.

Version-distribution health across the ecosystem

Of 95 go.mod files referencing go-finding: 60 on v1.14.0 (current), 31 on v1.13.0, 3 on v1.11.0, 1 on v1.12.0. The SDK is on the current release, so no bump is required — but roughly a third of the ecosystem is one minor behind.

06e) WHAT WE SHOULD IMPROVE

  • Stop duplicating the dependency version in prose. Point at go.mod ("see go.mod for the pinned version") instead of hardcoding a number. Impact: kills the recurring drift class. Fix: rewrite the six stale references as pointers, not numbers.
  • Make doc/version drift fail CI. A tiny check that greps living docs for a version string that disagrees with go.mod would have caught every item in (d). Impact: drift becomes impossible to ship. Fix: add a script + CI job.
  • Track adoption as a metric, not a vibe. The dependency graph shows exactly who imports the SDK. Impact: adoption status stops being guesswork. Fix: record the consumer list in a living doc and refresh it periodically.
  • Close the loop after a bump. The v1.10.0 session explicitly listed "forgot benchmarks" and "didn't run gh pr list" — and four more bumps then landed with no changelog entry at all. The bump checklist exists but is not followed. Impact: the CHANGELOG hole in (d). Fix: enforce the checklist.
  • Cut releases on a cadence. Five bumps with no tag means consumers pin an artifact that no longer reflects master. Impact: value already delivered is undelivered. Fix: tag after green CI.
